01

White Noise

A focus and sleep app built on a multi-channel procedural ambient mixer. Nothing is a looped sample: the sound is generated.

  • Custom AVAudioSourceNode blocks generate audio in real time, with binaural-beat layers cross-faded by a Pomodoro timer.
  • MVVM architecture with singleton audio and display managers.
  • SwiftUI interface with glassmorphic materials and procedural animation; an OLED-safe low-luminance mode for overnight use.
SwiftUI · AVAudioEngine
2026
02

Harmonica Tuner

Real-time pitch detection for 10-hole diatonic harmonicas — it tells you which hole, whether to blow or draw, and how many cents off you are.

  • Bridged Android's native AudioRecord to the JavaScript thread for low-latency PCM streaming.
  • YIN algorithm for fundamental-frequency estimation, mapped to the harmonica layout.
  • I wrote up the signal processing behind it ↗
React Native · Expo
2026
03

Ghosted

A conversation-exit assistant: paste the message you just received, get a polite way out drafted by an LLM.

  • Groq LLM inference behind two modes — generate an excuse, or soften a reply you already wrote.
  • UIKit with Storyboards and programmatic UI; usage streaks persisted locally.
UIKit · Groq API
2026
04

SubSafe

An offline subscription tracker, published on Google Play.

  • Local-first by design: no account, no cloud, no data leaving the device.
  • Built with React Native and Expo as an end-to-end publishing exercise.
React Native
